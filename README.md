# auto_seed — роботизированный посев семян в кассеты

Командный проект **«Роботизированный посев»** (Олимпиада Иннагрика 2026, агротех, АТ10-2).

Дозатор движется по балке (ось X) над кассетой 4×6 ячеек, конвейер подаёт кассету рядами (ось Y), а диск с лунками на сервоприводе выдаёт семена. Сеется не вся кассета, а только ячейки, отмеченные в карте посева.

В репозитории две части:

| Папка | Что внутри |
|---|---|
| [`device/`](device) | Прошивка ESP32 и схема для симулятора Wokwi |
| [`model/`](model) | Визуализация процесса посева на Python (pygame) |

**Схема в Wokwi:** https://wokwi.com/projects/481107644420984833

## 1. Устройство (ESP32 + Wokwi)

### Компоненты

- ESP32 DevKit C V4
- 2 × драйвер шагового двигателя A4988
- Шаговый двигатель оси X — перемещение дозатора вдоль ряда
- Шаговый двигатель оси Y (NEMA 17) — конвейер, подача кассеты на следующий ряд
- Сервопривод — диск-дозатор с лунками
- 2 концевика (левый и правый) — кнопки
- Переключатель режима (змейка / зиг-заг)
- Кнопка START и кнопка E-STOP

### Подключение

| Функция | GPIO ESP32 | Режим |
|---|---|---|
| Сервопривод (диск), PWM | 18 | LEDC, 50 Гц, 14 бит |
| Ось X: STEP / DIR (драйвер `drv2`) | 26 / 27 | выход |
| Ось Y, конвейер: STEP / DIR (драйвер `drv1`) | 14 / 13 | выход |
| Левый концевик | 25 | INPUT_PULLUP |
| Правый концевик | 21 | INPUT_PULLUP |
| Переключатель режима | 22 | INPUT_PULLUP |
| START | 32 | INPUT_PULLUP |
| E-STOP | 33 | INPUT_PULLUP |

Все кнопки и переключатель активны по низкому уровню (замыкают вывод на GND). Драйверы A4988: `VDD`, `SLEEP`, `RESET` → 3V3, `ENABLE` → GND, `VMOT` → 5V. Серво питается от 5V.

### Параметры прошивки

| Параметр | Значение |
|---|---|
| Сетка кассеты | 4 ряда × 6 столбцов |
| Шаг между столбцами (X) | 40 мм = 3200 шагов |
| Шаг между рядами (Y) | 40 мм = 2400 шагов |
| Импульс STEP | 600 мкс HIGH + 600 мкс LOW |
| Поворот диска на одну подачу | 60° |
| Импульс серво | 500–2400 мкс (0–180°) |
| Пауза на падение семени | 500 мс |
| Скорость Serial | 115200 |

Карта посева (`seedingMap`, `1` — сеять, `0` — пропустить), 18 семян на кассету:

```
ряд 1: 1 1 0 0 1 1
ряд 2: 0 1 0 1 1 1
ряд 3: 1 1 0 1 1 1
ряд 4: 1 1 1 0 1 1
```

### Алгоритм работы

1. Нажатие **START** → прошивка читает переключатель режима.
2. **Прайминг диска:** серво проходит 0 → 60 → 120 → 180° и обратно, чтобы заполнить лунки.
3. Посев ряда: дозатор проходит 6 столбцов, в ячейках с `1` диск поворачивается на 60° и семя падает.
4. В конце ряда дозатор ждёт срабатывания концевика.
5. Конвейер сдвигает кассету на 3 см к следующему ряду. После 4 рядов в мониторе выводится `КАССЕТА ГОТОВА!`.

**Режимы** (переключатель на GPIO 22):

- **Змейка** (HIGH) — ряды проходятся поочерёдно слева направо и справа налево, посев в обе стороны.
- **Зиг-заг** (LOW) — посев только при движении вправо, обратно дозатор возвращается без посева.

**E-STOP** останавливает шаговые двигатели и переводит систему в аварийный останов. Чтобы снова запустить, нужен сброс платы.

### Запуск в Wokwi

1. Откройте [проект в Wokwi](https://wokwi.com/projects/481107644420984833) и нажмите ▶.
2. Откройте Serial Monitor, чтобы видеть ход посева.
3. Управление с клавиатуры (сначала кликните по схеме):

| Клавиша | Кнопка |
|---|---|
| `4` | START |
| `5` | E-STOP |
| `2` | левый концевик |
| `3` | правый концевик |

В конце каждого ряда нажмите нужный концевик: `3`, если дозатор ехал вправо, или `2`, если влево.

Чтобы собрать проект в Wokwi с нуля, создайте проект ESP32 и вставьте содержимое `device/sketch.ino` в `sketch.ino`, а `device/diagram.json` — в `diagram.json`.

## 2. Визуализация (Python)

`model/main.py` — анимация работы посевного модуля: вид сверху на балку, дозатор и кассету, вид сбоку на бункер, шестерёнку с 6 лунками и падение семени в ячейку.

Сценарий включает 2 кассеты по 4×6 со своими картами посева и отказы подачи:

- **«пусто»** — семя не выпало, система проверяет ячейку и подаёт ещё раз;
- **«два»** — выпало два семени, лишнее убирается, подача повторяется.

На каждую ячейку даётся до 3 попыток. Сейчас сценарий задан в коде. Позже его планируется заменить разбором логов с устройства.

### Установка и запуск

```bash
cd model
pip install -r requirements.txt   # pygame-ce 2.5.8
python main.py
```

Нужен Python 3.

### Управление

| Клавиша | Действие |
|---|---|
| `Пробел` | пауза / продолжить |
| `↑` | ускорить в 2 раза (до ×16) |
| `↓` | замедлить в 2 раза (до ×0.25) |
| `R` | начать сценарий заново |
| `Esc` | выход |

### Что на экране

- Верхняя плашка: текущий шаг, скорость, пауза.
- Слева: балка с концевиком, дозатор и кассета. Цвета ячеек: синий — нужно посеять, серый с чертой — не сеять, зелёный — семя есть, красный — два семени. Жёлтым выделена активная ячейка.
- Статистика: номер кассеты, сколько посеяно из нужного, число повторов, очередь.
- Справа, вид сбоку: бункер, шестерёнка и её угол, окно выдачи, ячейка в разрезе.
- Внизу: журнал последних шагов.
